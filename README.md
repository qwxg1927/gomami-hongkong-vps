## 二、香港 VPS 测速到底看什么指标

很多人测速就是开个 speedtest 看个下载数字，这其实远远不够。一份能反映真实使用体验的香港 VPS 测速报告，至少要覆盖以下五个维度。

**1. 往返延迟（RTT / Ping）**

延迟决定了"打开页面那一刻"的体感。香港机房到大陆一线城市的物理 RTT 一般在 30-50ms 区间，二线城市 50-80ms。超过 100ms 就说明线路绕路或经过劣质中转，建站和 API 都会觉得"卡"。

**2. 三网分别测速**

电信、联通、移动三条线路在中国的网络架构里是各自独立的，没有任何一条线路能同时让三家都快。所谓"三网优化"，指的就是分别对接电信 CN2、联通 9929（AS4837）、移动 CMIN2（CMI）三条精品回程线路。测速时必须分运营商看，否则数据就是糊弄人。

**3. 晚高峰时段表现**

晚高峰（通常 20:00-23:00）才是真正的"照妖镜"。很多号称 1Gbps 端口的 VPS，白天能跑满，晚高峰只剩 100-200Mbps，甚至更低。判断一个香港 VPS 值不值得买，晚高峰实测比标称带宽重要十倍。

**4. 回程路由追踪**

回程路径决定了数据从香港回到大陆用户手里的路线。绕美国、绕日本、走普通 163 线路，都会让延迟和丢包大幅上升。traceroute 一跑，线路优劣一目了然。

**5. 丢包率与抖动**

延迟低不代表稳定，丢包率高于 1% 就会让 TCP 重传飙升、SSH 输入出现"鬼畜感"。抖动（jitter）大的线路，实时音视频和游戏服务器会非常难受。

中国电信的下一代承载网，分 CN2 GT 和 CN2 GIA 两档。GIA 是真精品，回程全程走 CN2 不掉级，延迟稳定、丢包低，是建站和跨境业务的"金标准"。代价是贵，香港 CN2 GIA 的带宽成本是普通 163 线路的几倍。

中国联通的精品骨干网，9929 比 4837 更优。回程走 9929 的香港 VPS，联通用户的延迟可以压到 30-40ms，晚高峰也不容易掉速。9929 资源稀缺，很多商家只敢给"部分时段走 9929"。

**移动 CMIN2（CMI 移动国际）**

中国移动的国际出口精品线路，回程走 CMIN2 可以避开移动普通出口的拥塞。移动用户量级大但精品线路少，能稳定走 CMIN2 的香港 VPS 在移动端体验会非常顺。
